## 基本コマンド

キャラクター:
`/char_create 勇者`
`/char_list`
`/char_show`
`/char_use 勇者`
`/char_delete 勇者`
`/char_reset`

敵:
`/enemy_list`
`/enemy_info dragon 10`
`/battle_start dragon 10`

戦闘:
`/battle_status`
`/battle_attack`
`/magic_cast 火炎`
`/battle_run`

PvP:
`/pvp_start 勇者 魔王`
`/pvp_attack`
`/pvp_magic 火炎`
`/pvp_status`
`/pvp_end`

## 敵レベル
例:
`/battle_start slime 1`
`/battle_start dragon 10`
`/battle_start void_beast 50`

敵のレベルが高いほど、敵のHP・攻撃・防御・獲得EXP・Goldが上がります。

## 戦闘終了時の仕様
戦闘前のHP/MPを保存します。
勝利・敗北・逃走のいずれでも、戦闘終了時にHP/MPを戦闘前の値へ戻します。
ただし、勝利報酬のEXPとGoldは保存されます。

## GitHub Pages

## Goldショップ（v2）

### ステータス振りなおし
`/status_reroll`

スライム10体分のGold（100 Gold）を使用して、
STR / DEX / INT / POWをランダムに振りなおします。

### ステータスを1個+1
`/status_up STR`
`/status_up DEX`
`/status_up INT`
`/status_up POW`

スライム20体分のGold（200 Gold）を使用して、
指定したステータスを+1します。

日本語でも指定できます:
`/status_up 筋力`
`/status_up 敏捷`
`/status_up 知力`
`/status_up 精神`


## 最終アップデート：アイテム・装備

### 戦闘中アイテム
`/item_use potion`
- HPを50回復
- 戦闘中のみ使用可能
- 使用すると敵のターンになる

`/item_use ether`
- MPを30回復
- 戦闘中のみ使用可能
- 使用すると敵のターンになる

### 自動アイテム
- HPが25%以下になると、回復薬を自動使用
- MPが15%以下になると、魔力薬を自動使用
- アイテムがある場合のみ発動

### レア装備ドロップ
敵撃破時に一定確率でランダムな武器または防具が落ちます。
★1〜★10のランクがあります。

防具:
- ★1ごとに防御力+2
- ★10なら防御力+20

武器:
- ★1〜★10
- 攻撃力+10

### 装備変更
`/item_list` で装備品一覧を確認。
`/equip weapon 番号`
`/equip armor 番号`

装備品はステータス画面にも表示されます。


## 追加修正（v2）

### 防具名の連携
防具は、ドロップ時に生成された
「★ランク + 防具名 + 防御力」
のデータをそのままアイテムとして保存します。

そのため、アイテム一覧・装備中表示・ステータス画面で同じ防具名が連携して表示されます。

### アイテム一覧から装備
`/item_list` で番号を確認します。

例:
`1. 防具 ★4 月影のローブ 防御+8`

その後、
`/equip armor 1`

で装備できます。

武器も同じです:
`/equip weapon 2`

### ヘルプ
`/help` にアイテム一覧と、一覧の番号を使って装備する方法を追加しました。


## 追加修正（v3）：防具の★ランクと名前を連動

防具は★ランクが高いほど、より強そうな名前からランダム生成されます。

例:
- ★1: 布の鎧 / 旅人の革鎧
- ★3: 騎士の鎧 / 月影のローブ
- ★5: 黒曜の重装 / 竜鱗の鎧
- ★7: 神域の法衣 / 古竜の鎧
- ★9: 終焉の鎧 / 神殺しの甲冑
- ★10: 創世の鎧 / 万象を統べる鎧 / 神話級・天命の鎧

防御力の計算はこれまで通り、
★1につき防御力+2です。


## 追加修正（v4）：武器の★ランクと名前を連動

武器も★ランクが高いほど、より強そうな名前からランダム生成されます。

例:
- ★1: 鉄の剣 / 旅人の短剣
- ★3: 騎士の剣 / 月影の刃
- ★5: 黒曜の斧 / 竜牙の槍
- ★7: 神域の杖 / 古竜の大剣
- ★9: 終焉の魔剣 / 神殺しの剣
- ★10: 創世の剣 / 万象を断つ聖剣 / 神話級・天命の剣

武器の攻撃力ボーナスはこれまで通り攻撃力+10です。
